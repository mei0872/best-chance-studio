How the formatting works

  • ✂️Character limits enforced — the formatter trims to fit the platform limit. It breaks at sentence boundaries where possible to avoid cutting mid-thought.
  • 📋Templates append after the story — your rescue boilerplate comes last. The dog's story always gets priority.
  • ⚠️Budget warning — if templates are long enough to crowd the dog story below ~300 chars, the formatter tells you which template is the problem.
  • 🔌API-compatible — this tool matches the POST /story/format spec exactly. Platform implementations can call this logic server-side.

For platform builders — API contract

This tool implements the POST /story/format endpoint spec from TASKS.md. Input: description, target, optional templates[]. Output: formatted, char_count, limit, status, templates_included[], optional template_warning. Standalone BCS omits templates[] — coached story only. Same logic, both cases.
